Nikon Camera Bridge

Monorepo: one logical core will own USB, expose a Media Foundation virtual camera for fan-out video, and serve a separate HTTP control API. This window is the desktop shell; see the repo README for architecture diagrams.

Workspace layout

packages/core — shared types and state helpers.
packages/api — HTTP control server (stub routes). Run pnpm run start:api from the repo root.
packages/video — MF virtual camera adapter (planned).
apps/desktop — this Electron app.

Target layering

  1. Physical USB — WinUSB or still-image negotiation so only the bridge opens the device.
  2. Demux — read UVC-style video (or PTP live view where applicable) and PTP control channels in one coordinator.
  3. Virtual sink — Windows Media Foundation virtual camera, DirectShow filter, or OBS VirtualCam-style output so Zoom, Teams, and OBS see one predictable device owned by the bridge.
  4. Control API — HTTP JSON in packages/api (future PTP mapping).
