# Contributing

Thanks for your interest in **Webcam Bridge for Nikon** (this repository’s desktop app and libraries).

## How to contribute

- **Issues:** Bug reports, feature ideas, and packaging notes are welcome. For bugs, include OS version, camera model if relevant, and steps to reproduce.
- **Pull requests:** Keep changes focused, match existing style and tooling, and run the checks that apply to your change (for example `pnpm install` then the workspace `build` / `typecheck` scripts your edits touch).
